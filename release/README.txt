Jump for Minecraft Dungeons (v1.17.0.0, Steam)
==============================================

Lets the hero jump about 2.5 blocks high, with Minecraft Dungeons II style
controls: Space jumps and the forward roll moves to R.

REQUIREMENTS
- Dungeons Blueprint Loader 1.0 (Blueprint-Loader.pak) in the same ~mods folder.

INSTALL
1. Copy Jump.pak into:
   <Steam>\steamapps\common\MinecraftDungeons\Dungeons\Content\Paks\~mods\
2. Start the game.

CONTROLS
Keyboard & mouse
- Space         Jump (no longer rolls or interacts; use Left Mouse to interact)
- R             Forward roll (was Space)
- Mouse 4       Roll (unchanged)
Controller
- LT            Jump
- D-pad Left    Quick-chat wheel in online games (was LT; not tested yet)

You can only jump from the ground. Works together with the Third-Person
Camera and Analog Movement mods.

UNINSTALL
Delete Jump.pak from ~mods. There is no in-game toggle.
